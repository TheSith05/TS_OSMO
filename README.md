# OsmoFilter — счётчик ресурса фильтров обратного осмоса

> Контроллер на ESP32-C3 с веб-интерфейсом: считает пролитую воду по импульсному датчику потока, отслеживает остаточный ресурс каждой ступени очистки и подсвечивает на адресной ленте, какой картридж пора менять.

## Возможности

- 📊 Подсчёт общего пробега (литры) по датчику потока YF-201
- 🧪 Калибровка «импульсов на литр» — без перепрошивки, через веб-интерфейс
- 🔧 Учёт ресурса до 6 ступеней фильтрации (название, ресурс в литрах, дата установки)
- 🎨 Цветовая индикация по шкале: зелёный → жёлтый (≤50%) → красный (≤15%)
- 💡 Адресная светодиодная лента: градиент ресурса, мигающий красный при перерасходе
- 🌐 Веб-интерфейс: мониторинг, сброс ресурса выбранного картриджа, скрытие настроек
- 💾 Хранение всех настроек и пробега в файловой системе (LittleFS), переживает перезагрузку
- ♻️ Factory reset замыканием контакта при включении
- 📱 Работает в режиме точки доступа — не нужна домашняя сеть

## Железо

| Компонент | Примечание |
| --- | --- |
| ESP32-C3 SuperMini | контроллер |
| Датчик потока YF-201 | 450 имп/л по даташиту, калибруется |
| WS2812B, 6 светодиодов | индикация ступеней |
| Резистор 20 кОм | согласование уровней (см. схему) |

### Подключение датчика потока

Сигнальный выход датчика имеет внутреннюю подтяжку 10 кОм к его питанию (5 В). Внешний резистор 20 кОм на землю образует делитель: высокий уровень ≈ 3.3 В — безопасно для ESP32.

```javascript
YF-201                ESP32-C3
──────                ────────
Красный (5V)      →   5V (VBUS)
Чёрный (GND)      →   GND
Жёлтый (сигнал)   →   GPIO2 ──┬── 20 кОм ── GND
                              └── 100 нФ ── GND (подавление наводок)
```

### Светодиоды

`GPIO0` → DIN ленты WS2812B (6 светодиодов, GRB). ⚠️ GPIO0 — страп-пин: при прошивке ленту лучше отключить.

### Factory reset

Замкнуть **GPIO6 на GND** в момент подачи питания — база данных будет стёрта, при следующей загрузке устройство предложит настройку заново.

## Прошивка

Платформа — [PlatformIO](https://platformio.org/) (или Arduino IDE с выбранной платой «ESP32C3 Dev Module»).

Зависимости (`platformio.ini`):

```ini
[env:esp32-c3]
platform = espressif32
board = esp32-c3-devkitm-1
framework = arduino
upload_speed = 921600
monitor_speed = 115200
lib_deps =
	GyverLibs/Settings
    FastLED/FastLED
    GyverLibs/GTimer
```

1. Залить прошивку
2. Подключиться к Wi-Fi сети `OsmoFilter` (пароль по умолчанию — см. код / настройка)
3. Открыть в браузере **http://192.168.4.1**

## Первый запуск и настройка

1. Устройство стартует в режиме мастера настройки: укажите импульсы/литр, количество ступеней, названия и ресурсы фильтров, текущий пробег (если система уже использовалась).
2. Подтвердите — даты установки проставятся автоматически, устройство перейдёт в режим мониторинга.
3. **Калибровка:** пролейте измеренный объём (5–10 л), посмотрите счётчик пульсов, поделите пульсы на литры, введите результат в «Импульсов на литр».

## Эксплуатация

- **Сброс ресурса** (после замены картриджа): веб-интерфейс → «Обслуживание» → выбрать фильтр → «Сбросить ресурс». Фиксируются дата установки и текущий пробег.
- Светодиод над ступенью горит зелёным (новый) → жёлтым → красным → мигает красным (перерасход).
- Веб-интерфейс можно свернуть до «только мониторинг»: свитч «Показать настройки».

## Как это устроено (кратко для разработчиков)

- **GyverDBFile** (GyverLibs) — база «ключ → значение» в ОЗУ с автосохранением в файл `/data.db` по таймауту. Ключи — compile-time хэши (`DB_KEYS`), настройки читаются напрямую из БД, горячие счётчики живут в переменных и сбрасываются пачками (раз в 5 л) для экономии ресурса flash.
- **Settings** (GyverLibs) — веб-интерфейс, привязанный к тем же ключам БД: виджет = ячейка.
- Датчик опрашивается прерыванием с программным фильтром 2 мс (защита от наводок соленоида).
- Остаток/цвет/флаг перерасхода считается в одном месте (`calcFilterState`) и используется и вебмордой, и лентой.
