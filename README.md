# OsmoFilter — счётчик ресурса фильтров обратного осмоса

> Контроллер на ESP32-C3 с веб-интерфейсом: считает пролитую воду по импульсному датчику потока, отслеживает остаточный ресурс каждой ступени очистки и подсвечивает на адресной ленте, какой картридж пора менять. Чуть подробнее на [https://habr.com/](https://alexgyver.ru/)

## Возможности

- 📊 Подсчёт общего пробега (литры) по датчику потока YF-S201
- 🧪 Калибровка «импульсов на литр» — без перепрошивки, через веб-интерфейс
- 🔧 Учёт ресурса до 6 ступеней фильтрации (название, ресурс в литрах, дата установки)
- 🎨 Цветовая индикация по шкале (Вебморда): зелёный (100%-51%)→ жёлтый (50%-16%) → красный (15%-0%)
- 💡 Адресная светодиодная лента: градиент ресурса, мигающий красный при перерасходе
- 🌐 Веб-интерфейс: мониторинг, сброс ресурса выбранного картриджа, скрытие настроек
- 💾 Хранение всех настроек и пробега в файловой системе (LittleFS), настройки сохраняются при перезагрузке
- ♻️ Factory reset замыканием контакта при включении
- 📱 Работает в режиме точки доступа

| Немного проводов | Куда же без них |

### Подключение датчика потока

Сигнальный выход датчика имеет внутреннюю подтяжку 10 кОм к его питанию (5 В) (Проверено через делитель, т.к. он работал не корректно). Внешний резистор 20 кОм (У меня 2 по 10 кОм последовательно) на землю образует делитель: высокий уровень ≈ 3.3 В — безопасно для ESP32. (На пин esp32 падает как сигнал, так и резистор на 20 кОм который в свою очередь кинут на GND)

```javascript
YF-S201                ESP32-C3
──────                ────────
Красный (5V)      →   5V (VBUS)
Чёрный (GND)      →   GND
Жёлтый (сигнал)   →   GPIO2 ── 20 кОм ── GND
```

### Светодиоды

`GPIO0 ── 220 Ом ──` DIN ленты WS2812B (6 светодиодов, GRB).

### Factory reset

Замкнуть **GPIO6 на GND** в момент подачи питания — база данных будет стёрта, при следующей загрузке устройство предложит настройку заново (Предполагается снятие контролера с платы и замыкание скрепкой).

## Прошивка

Платформа — [PlatformIO](https://platformio.org/) (или Arduino IDE с выбранной платой «ESP32C3 Dev Module»).

Зависимости (`platformio.ini`):

```ini
[env:esp32-c3]
platform = espressif32
board = esp32-c3-devkitm-1
framework = arduino
upload_speed = 921600
monitor_speed = 115200
lib_deps =
	GyverLibs/Settings
    FastLED/FastLED
    GyverLibs/GTimer
```

1. Залить прошивку
2. Подключиться к Wi-Fi сети `OsmoFilter` (пароль по умолчанию — см. код / настройка)
3. Открыть в браузере **http://192.168.4.1**

## Первый запуск и настройка

1. Устройство стартует в режиме мастера настройки: укажите импульсы/литр, количество ступеней, названия и ресурсы фильтров, текущий пробег (если система уже использовалась).
2. Подтвердите — даты установки проставятся автоматически, устройство перезагрузится и перейдёт в режим мониторинга (Если Вы меняли SSID/пароль, потребуется подключится уже к новой сети).
3. **Калибровка:** пролейте измеренный объём (5–10 л), посмотрите счётчик пульсов, поделите пульсы на литры (вактические литры), введите результат в «Импульсов на литр».
P.S. Если меняете пароль, он должен быть НЕ менее 8 символов!

## Эксплуатация

- **Сброс ресурса** (после замены картриджа): веб-интерфейс → «Обслуживание» → выбрать фильтр → «Сбросить ресурс». Фиксируются дата установки и текущий пробег.
- Светодиод над ступенью горит зелёным (новый) → жёлтым → красным → мигает красным (перерасход).
- Веб-интерфейс можно свернуть до «только мониторинг»: свитч «Показать настройки» чтобы "Вспомнить всё"))

## Как это устроено

- **GyverDBFile** (GyverLibs) — база «ключ → значение» в ОЗУ с автосохранением в файл `/data.db`. Настройки читаются напрямую из БД, "горячие" счётчики живут в переменных и пишутся раз в 5 л. для экономии ресурса flash.
- **Settings** (GyverLibs) — веб-интерфейс, привязанный к тем же ключам БД: виджет = ячейка.
- Датчик опрашивается прерыванием с программным фильтром 2 мс (защита от наводок).
- Остаток/цвет/флаг перерасхода считается в одном месте (`calcFilterState`) и используется и вебмордой, и лентой.
